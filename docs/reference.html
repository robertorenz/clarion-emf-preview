ClassesEmfPreviewClass

Declared in EmfPreview.inc, implemented in EmfPreview.clw, derived from PrintPreviewClass so everything ABC gives a previewer — Init, ImageQueue, CurrentPage, PagesToPrint, PrintOK, Errors, Translator, AskPrintPages, the target selector — is still there. This volume lists what EmfPreview adds. Each entry carries a worked line of Clarion; the tables are read out of the include file and cannot drift from the code.

EmfPreviewClass       CLASS(PrintPreviewClass),TYPE,|
                        MODULE('EmfPreview.CLW'),LINK('EmfPreview.CLW')
