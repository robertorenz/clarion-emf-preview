TemplatesThe two extensions

One template file, EmfPreview.tpl, family ABC: EMF Unicode Previewer for Clarion 12 Unicode - v1.1.

ExtensionPut it onWhat it does
EmfPreviewGlobal
EMF Unicode Previewer - Global (activate)		the application, onceincludes EmfPreview.INC, sets the global Print Previewer class to EmfPreviewClass, and holds the defaults every report inherits — sidebar, zoom, marks, wheel, colours
EmfPreviewer
EMF Unicode Previewer - Report options		a Report procedure (Report procedures only; requires EmfPreviewGlobal)a window title for this report, local overrides of the global options, or Use unticked to fall back to the classic ABC window

Nothing needs the second extension. With only the global one every report procedure gets the EMF previewer with the global settings. Add the report extension where a report wants a title of its own, different settings, or the classic window.

Removing tab

Not a prompt — a page of instructions, because the swap the extension performs outlives it. The extension sets Global Properties → Classes → Report → Print Previewer from PrintPreviewClass to EmfPreviewClass, and Clarion stores that value in the .app. Delete the extension and the reports keep the EmfPreview previewer.

  1. Tick Disable this template on the General tab.
  2. Generate once — the Print Previewer class is put back to PrintPreviewClass.
  3. Delete the extension and generate again.

Already deleted it? Set the Print Previewer class back by hand and generate all. The class is linked into every module that uses it, so a leftover reference compiles and runs rather than GPFing; the testapp\removal.txa and disable.txa builds are the regression tests for both paths.

How the class swap works

ABC report procedures declare their previewer from the global symbol %PrintPreviewType. The extension sets it at the start of every generation and restores it when disabled or when Replace is off, so the value the .app keeps is always consistent with the extension's own settings:

#ATSTART
  #IF(NOT %EmfPrvDisable AND %EmfPrvReplaceAll)
    #SET(%PrintPreviewType,'EmfPreviewClass')
  #ELSIF(%PrintPreviewType = 'EmfPreviewClass')
    #SET(%PrintPreviewType,'PrintPreviewClass')
  #ENDIF
#ENDAT

Multi-DLL suites: add the global extension to every application. Each module links its own copy of the class; there is nothing to export.

TemplatesWhere the code lands

No embed points of its own — the template only writes into existing ABC points:

ExtensionEmbed pointPriorityCondition
EmfPreviewGlobal%AfterGlobalIncludes—NOT %EmfPrvDisable

Priority 8490 in WindowManager.Init is after the report template has created the Previewer object and before the window opens, so the options are in place for Display.

Regenerate to pick up template changes

Prompt changes reach the source on the next generate. Class changes are in EmfPreview.clw and reach the EXE on the next compile — and because the class is linked, not a DLL, every module that uses it has to be rebuilt.
